## Работа с тестовыми данными 

Windows:
Включить виртуальное окружение (venv) перед

Чтобы посмотреть какие файлы загружены в систему: 
curl.exe -s "http://localhost:9200/documents/_search?pretty" | Select-String '"file_name"'

curl.exe -X DELETE "http://localhost:9200/documents"

Лиза Р: /src: `config.py`; `ingest.py`; `chunking.py`; `index.py`; `search.py`; `run_all_from_data.py`; `test_ingest.py`; `test_chunking.py`; `test_index.py`; `test_search.py`

- `config.py` хранит все настройки проекта: пути к папкам (`data/raw`, `ingest_output`), настройки Elasticsearch, размеры чанков, лимиты OCR и поддерживаемые форматы файлов. Позволяет менять параметры без правки основного кода.

- `ingest.py` модуль извлечения текста. Умеет читать `.md`, `.docx` и `.pdf`. Очищает текст от битых кодировок, шапок, колонтитулов и номеров страниц. Для PDF определяет колонки и размеры шрифтов (чтобы найти заголовки). Определяет язык документа. Сохраняет результат в виде структурированного JSON-файла в папку `ingest_output/`.

- `chunking.py` модуль нарезки. Берет текст из `Document` и режет его на куски (около 1000 символов). Старается резать по границам предложений. Добавляет перекрытие (overlap), чтобы не терять смысл на стыках, при этом не разрывая слова. Восстанавливает иерархию разделов (section_path) для каждого куска (важно для DOCX и MD). Присваивает каждому куску стабильный `chunk_id`.

- `index.py` модуль работы с Elasticsearch. Создает индекс с анализатором русского языка. Записывает нарезанные куски в базу данных пачками (bulk). Если такой `chunk_id` уже есть, обновляет его.

- `search.py` модуль поиска. Принимает вопрос пользователя, отправляет его в Elasticsearch и возвращает список самых релевантных кусков. Использует поиск по точной фразе и буст по заголовкам разделов, чтобы находить именно те абзацы, где есть ответ.

Точки входа и тесты

- `run_all_from_data.py` главный скрипт пайплайна. Запускает всю цепочку: `ingest папки data/raw → chunking → index в Elasticsearch`. Используется для первичной загрузки базы знаний.

- `test_run.py` тестовый скрипт для проверки извлечения текста из конкретного файла (выводит текст и созданный JSON).

- `test_chunking.py` тестовый скрипт для просмотра результатов нарезки (показывает ID, разделы, перекрытия и полный текст кусков).

- `test_index.py` тестовый скрипт для проверки подключения к Elasticsearch и загрузки тестового документа в базу.

- `test_search.py` тестовый скрипт, который задает несколько вопросов и показывает, какие куски текста нашлись в базе.

- `requirements.txt` добавлены `ftfy>=6.1.3` (чинит битые кодировки), `py3langid>=0.2.2` (определяет язык документа), `PyMuPDF>=1.24.0` (вместо `pypdf`)
