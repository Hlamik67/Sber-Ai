# Корпус

Сюда кладутся документы, которые режем. Настоящих регламентов Сбера нет: три файла рядом — открытая замена той же формы. В отчёте так и пишем.

После 21 ноября файлы не менять, чтобы улучшить цифры.

## Состав корпуса

| Файл | Сценарий | Раздел |
|------|----------|--------|
| `dostup_k_sistemam.md` | условия | информационная безопасность |
| `poryadok_otpuska.md` | срок | кадры |
| `reglament_komandirovki.md` | документ | административный |

## Формат

- Один файл — один документ, `.md`, UTF-8.
- Заголовки `##` внутри файла — это будущие `section` в чанках.
- У каждого куска будет постоянный `chunk_id` — по нему считается попадание.

## Про `data/qa.jsonl`

Поле `chunk_id` заполняется Лизой К по мере появления чанков у Лизы Р. До 19 октября может быть пустым.

Поле `wording`:
- `"как в документе"` — вопрос словами регламента;
- `"своими словами"` — как спросил бы сотрудник, не читая регламент.
